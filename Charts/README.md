# Logistics Data Analysis Visualizations

This folder contains the visualization outputs generated during the Advanced Data Analysis and Visualization in Logistics project.

The charts were created using Python to explore logistics performance, identify operational patterns, evaluate cost drivers, and communicate analytical findings clearly.

## Visualizations Included

1. Delivery Time Distribution
2. Transportation Cost Distribution
3. Transportation Cost vs Shipment Distance
4. Transportation Cost vs Shipment Volume
5. Average Transportation Cost by Transport Mode
6. Warehouse Processing Time vs Shipment Delay
7. Shipment Delay vs Customer Rating
8. Logistics Correlation Matrix
9. On-Time vs Delayed Shipments
10. Monthly Shipment Volume

## Purpose of the Visualizations

The visualizations support the interpretation of important logistics performance metrics such as delivery time, transportation cost, shipment volume, warehouse processing time, shipment delays, transport mode performance, customer ratings, and monthly shipment activity.

Histograms were used to examine distributions, scatter plots were used to investigate relationships between quantitative variables, bar charts were used for categorical performance comparisons, a correlation heatmap was used to summarize relationships among logistics variables, and a line chart was used to examine monthly shipment activity.

## Important Note

The dataset used in this project is hypothetical and was created for analytical and educational purposes. Therefore, the visualizations demonstrate logistics data analysis techniques and should not be interpreted as the actual performance of a real logistics organization.
